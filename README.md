### 🚀 Featured project — [PoliPro](https://polipro.net)

> **Engineering exams, actually understood.**

**PoliPro** is a study platform for engineering students at the Politecnico di Bari, which I designed and launched. It is now used by **200+ registered students**.

- 📚 Step-by-step lessons for **14 engineering exams**
- 🧊 Interactive **3D models** you can rotate with your fingers
- ✅ Exercises with **instant correction** and error diagnosis (unit, concept, procedure, calculation)
- 🧠 **Active recall** and **spaced repetition**
- 📝 Exam simulators (written, pre-oral, oral)
- 💳 Freemium model with online payments
